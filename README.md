# Agent Nexus for Zed

Adds the [Agent Nexus](https://agentnexus.app) MCP server to Zed's Agent Panel: search 690+ live-probed APIs, MCP servers and CLIs in plain language, with health, auth shape and limits.

No account needed (100 calls/day anonymous). Free key with 1,000 calls/day: https://agentnexus.app/free-key

Hosted endpoint: `https://agentnexus.app/mcp` (Streamable HTTP). This extension bridges it to Zed via `mcp-remote`.
